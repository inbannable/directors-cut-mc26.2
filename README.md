# Director's Cut

Fabric 0.19.3 / Minecraft 26.2 server-authoritative story director.

Build with `./build.sh`. The script uses HMCL's bundled Java 25 toolchain and writes
`directors-cut-1.0.0+mc26.2.jar` into the containing `mods` directory.

Operator commands:

- `/director hint` — replay the latest subtle clue
- `/director hints on|off` — player preference, enabled by default
- `/director status`
- `/director events`
- `/director event <id>`
- `/director random`
- `/director cooldown reset`
- `/director debug on|off`
